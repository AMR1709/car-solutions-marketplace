# Car Solutions Marketplace

A Pakistan-first multi-vendor marketplace for buying and selling
automotive parts and accessories.

## Main goal

Help buyers find trusted parts that are compatible with their vehicles,
while giving verified sellers tools to manage products, inventory,
orders and payouts.

## Initial users

- Buyers
- Verified sellers
- Car Solutions administrators

## Phase 1 scope

- Browse and search car parts
- Vehicle compatibility
- Buyer and seller accounts
- Product and inventory management
- Shopping cart and orders
- Shipping, returns and buyer protection
- Seller and administrator dashboards

## Planned technology

- TypeScript
- React and Next.js
- PostgreSQL
- Prisma
- Docker
- GitHub Actions
- Playwright
